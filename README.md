# Advanced OOP Concepts & Bank Account System in Dart

A comprehensive Dart console application demonstrating advanced Object-Oriented Programming (OOP) architectures, robust data encapsulation strategies, and clean code principles.

## 🚀 Key Features Implemented

* **Encapsulation & Validation:** Safe state management using file-private fields (`_`) and data-validating getters/setters.
* **Singleton Design Pattern:** Using factory constructors to safely cache and restrict class instantiation to a single shared footprint.
* **Mixins for Code Reuse:** Utilizing the `with` keyword to cleanly inject horizontal capabilities (`LoggerMixin`) across decoupled classes.
* **Operator Overloading:** Overriding the native `==` and `toString()` mechanisms to implement structured value-equality checking.
* **Composition Architecture:** Modeling real-world dependencies via a robust "has-a" structural layout (e.g., `Customer` possessing a `BankAccount`).
